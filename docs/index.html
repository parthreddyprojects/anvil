Two ways to use it

Guided Mode

Claude pauses at every step. You review findings, inject proprietary data, challenge the framing, redirect the analysis. Claude holds the full context — you bring the judgment. Co-solve the problem together.

Autopilot Mode

Claude runs end-to-end and narrates as it goes. You come back to a finished brief — 3-5 pages, sourced claims, proof charts, hypothesis graveyard. Good for speed.

Guided mode — Claude runs the method, you bring the judgment at every step
The Pipeline
STEP 0
Problem Statement
Claude challenges your framing. Neutral scope, decision sensitivity break point.
You: iterate until sharp
STEP 1
MECE Decomposition
4-10 buckets, 5-8 questions each. Adversarial audit + overlap check.
You: add buckets, flag overlap
STEP 2
Deep Research
120+ queries, 50+ articles. Live web search, not LLM knowledge.
You: inject proprietary data
STEP 3
Working Document
Per-bucket narrative + 2-5 page research debrief.
You: correct numbers, add context
STEP 4
Synthesis
Convergences, tensions, surprises, binding constraints, cascades.
You: spot connections Claude missed
STEP 5
Hypotheses
5-8 hypotheses, 6-point stress test, hypothesis graveyard.
You: add your own, provide evidence
STEP 6
Final Brief
3-5 pages. Title as conclusion, decisions with deadlines, data gaps.
You: sharpen with feedback
STEP 7
Proof Charts
4-6 charts. Data relationship → chart type. 3-second clarity test.
You: review, done
A completed run — "The Hormuz Endgame"
What makes it different

A chatbot gives you one pass. Anvil gives you eight, each building on the last. A chatbot never tries to disprove itself. Anvil has a hypothesis graveyard. A chatbot doesn't tell you what it doesn't know. Anvil lists every data gap, names who can fill it, and says by when.

Get started
# Install
pip install git+https://github.com/parthreddyprojects/anvil.git

# Set up Claude Code integration
anvil init

# Run inside Claude Code
/anvil

# Or run directly
anvil run --topic "What should OpenAI do as foundation models commoditize?" --audience "CEO, Board"

Requires: Python 3.10+, an Anthropic API key, and Claude Code for guided mode.
